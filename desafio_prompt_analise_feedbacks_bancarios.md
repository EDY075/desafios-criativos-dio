## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte do **Desafio Criativo da DIO**, com o objetivo de aplicar conceitos de **Engenharia de Prompt** para extrair insights a partir de feedbacks de clientes bancários utilizando Inteligência Artificial.

O desafio consiste em criar um prompt estruturado, capaz de orientar uma IA a identificar padrões, sentimentos, reclamações, elogios e oportunidades de melhoria em comentários de clientes.

# 🎯 Objetivo

Criar um prompt capaz de analisar feedbacks de clientes bancários e gerar informações úteis para apoiar a tomada de decisão das equipes responsáveis pela experiência do cliente e pelos canais digitais.

---

# 🧱 Passo 1 - Definição da Intenção

Quero que a IA analise feedbacks de clientes sobre serviços bancários digitais, incluindo aplicativo, Pix, cartão de crédito e atendimento por chat, para identificar reclamações frequentes, elogios e oportunidades de melhoria.

O resultado será utilizado pela equipe de experiência do cliente e pelos responsáveis pelos canais digitais para apoiar decisões relacionadas à melhoria dos serviços e ao aumento da satisfação dos clientes.

A entrega deve conter:

* Resumo executivo;
* Tabela com os principais temas;
* Exemplos de comentários;
* Recomendações práticas.

O resultado será considerado satisfatório se for claro, organizado e útil para priorizar ações.

---

# 🧱 Passo 2 - Contexto e Restrições

## Contexto

Os feedbacks analisados estão relacionados a:

* Aplicativo bancário;
* Pix;
* Cartão de crédito;
* Atendimento por chat.

## Dados Disponíveis

* Data do comentário;
* Canal de atendimento;
* Texto do feedback;
* Produto citado;
* Nota de satisfação de 1 a 5.

## Critérios de Análise

A IA deverá classificar os feedbacks por:

* Tema;
* Sentimento;
* Urgência;
* Produto relacionado;
* Impacto na experiência do cliente.

## Restrições

* Utilizar apenas os dados fornecidos;
* Não inventar números ou conclusões;
* Não expor informações pessoais ou sensíveis;
* Informar limitações quando os dados forem insuficientes;
* Utilizar linguagem simples e objetiva.

# 🧱 Passo 3 - Prompt Final

```text
Atue como um analista de dados e experiência do cliente especializado no setor bancário.

Sua tarefa é analisar feedbacks de clientes relacionados ao aplicativo bancário, Pix, cartão de crédito e atendimento por chat para identificar temas recorrentes, sentimentos dos clientes e oportunidades de melhoria.

Contexto:
A análise será utilizada pela equipe de experiência do cliente para priorizar melhorias nos canais digitais, reduzir problemas recorrentes e aumentar a satisfação dos usuários.

Dados disponíveis:
- Data do comentário;
- Canal de atendimento;
- Texto do feedback;
- Produto citado;
- Nota de satisfação de 1 a 5.

Instruções:

1. Classifique os feedbacks por tema, sentimento, urgência e produto relacionado.
2. Identifique padrões, reclamações, elogios e oportunidades.
3. Apresente evidências utilizando exemplos dos comentários.
4. Sugira ações práticas para as equipes responsáveis.

Formato da resposta:
- Resumo executivo com até 5 linhas;
- Tabela contendo tema, sentimento, evidência e ação sugerida;
- Lista com as três prioridades mais importantes.

Restrições:
- Use apenas os dados fornecidos;
- Não invente números ou causas;
- Não exponha dados pessoais ou sensíveis;
- Informe limitações quando necessário;
- Utilize linguagem clara e voltada para tomada de decisão.
```
